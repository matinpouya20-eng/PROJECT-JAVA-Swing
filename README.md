# PROJECT-JAVA-Swing

نسخه‌ی آموزشی سیستم مدیریت دانشگاه با رابط گرافیکی Swing و ساختار لایه‌ای.

## ساختار

- `model`: کلاس‌های داده‌ای مانند Student، Teacher و Offering
- `dao`: ذخیره و بازیابی اطلاعات با Serialization
- `bussiness`: منطق سیستم در `Universitysystem` و عملیات کاربردی در `OfferingCourseBL`
- `ui`: رابط گرافیکی Swing
- `Main.java`: فقط نقطه‌ی شروع برنامه؛ هیچ منوی command-line یا switch ندارد.

## اجرا در IntelliJ IDEA

1. فایل ZIP را از حالت فشرده خارج کن.
2. در IntelliJ از **File → Open** پوشه‌ی `PROJECT-JAVA-Swing` را انتخاب کن.
3. اگر IntelliJ پرسید، پروژه را به‌عنوان Maven project باز کن.
4. مطمئن شو Project SDK روی JDK 21 تنظیم شده است.
5. فایل `src/main/java/Main.java` را باز و Run کن.

Swing داخل JDK است؛ برای همین نسخه به dependency جداگانه‌ای نیاز ندارد.

## نکته

نسخه‌ی اصلی GitHub تغییر نکرده است. این یک نسخه‌ی جدا برای آزمایش معماری جدید است. نام package فعلی `bussiness` عمداً مانند پروژه‌ی قبلی نگه داشته شده تا انتقال مفاهیم ساده‌تر باشد.


## سازگاری فایل داده

این نسخه از فایل `university-data-swing.ser` استفاده می‌کند تا فایل سریال‌شده‌ی احتمالی پروژه‌ی قبلی بازنویسی نشود. انتقال داده‌ی سریال‌شده‌ی نسخه‌ی قبلی به این ساختار جداگانه انجام می‌شود و در این نسخه پیاده‌سازی نشده است.
